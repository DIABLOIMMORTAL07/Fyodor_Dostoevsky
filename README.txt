FYODOR DOSTOEVSKY — FIVE-PAGE LITERARY ARCHIVE
================================================
FILES
index.html       Home / portfolio-style landing page
biography.html   Biography and historical timeline
works.html       Selected works and publication table
ideas.html       Philosophical and literary themes
gallery.html     Photo gallery, video embed and validated contact form
style.css        Shared responsive stylesheet
script.js        Mobile navigation and JavaScript form validation

HOW TO RUN
1. Extract the ZIP.
2. Keep all files in the same folder.
3. Open index.html in a modern browser, or use VS Code + Live Server.

ASSIGNMENT REQUIREMENTS
HTML Form: gallery.html
Video: gallery.html (embedded YouTube search embed plus an external documentary search link)
Photos: across all five pages
Table: works.html
CSS Style Sheet: style.css
JavaScript Validation: script.js (name, email, topic, message and checkbox)

NOTES
- Independent educational project, not an official Dostoevsky website.
- Contact form validation is client-side only; messages are not sent or saved.
- Images and Google Fonts load from the internet.
- The YouTube search embed may not render in every browser; the adjacent link remains available. For a guaranteed specific video, replace the iframe src with a chosen YouTube /embed/VIDEO_ID URL.
- Historical images and third-party URLs can change; replace broken image URLs if needed.
